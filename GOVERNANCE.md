# Governance

sneakers-release is governed by the Sneakers-PAM project
[GOVERNANCE.md](https://github.com/Sneakers-PAM/.github/blob/main/GOVERNANCE.md).

Changes to `main` here reach every appliance that updates itself, so they land only through a pull
request approved by the project's release-review group, and a release is cut only after that group
has reviewed everything in it.
