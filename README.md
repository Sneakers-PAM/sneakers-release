# sneakers-release 🐹

> 🧭 Sneakers release manifest: every service, k0s and third-party component pinned to one version

## 📦 Install

```bash
go get github.com/Sneakers-PAM/sneakers-release
```

## 🛠 Develop

```bash
task build    # go build ./...
task test     # go test ./...
task lint     # gofmt check + golangci-lint + yamllint
task license  # check Apache-2.0 headers (golic)
```
